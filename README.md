# ELIL Jewellery E-commerce

A full-stack MERN e-commerce application for a premium jewellery brand.

## Tech Stack

- React
- Tailwind CSS
- Express.js
- Node.js
- MongoDB Atlas
- Cloudinary
- JWT Authentication

## Features

- User Authentication
- Product Catalog
- Shopping Cart
- Wishlist
- Orders
- Admin Dashboard
